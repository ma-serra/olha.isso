# Olha.Isso - Visualizador de Conversas WhatsApp

Aplicativo desenvolvido para clientes do escritório **Serra & Tuaf Advogados**.

## Sobre

Este aplicativo permite visualizar e exportar conversas do WhatsApp de forma organizada e profissional. Ideal para uso em processos jurídicos e documentação de provas digitais.

## Funcionalidades

- 📤 Upload de arquivos de conversa exportados do WhatsApp (.txt ou .zip)
- 👁️ Visualização organizada das mensagens
- 🔍 Filtros por data ou número de mensagens
- 💾 Exportação em HTML completo com mídias embutidas
- 🎵 Exportação de lista de áudios para transcrição
- 🔒 Opção de anonimização de usuários

## Como usar

1. Exporte sua conversa do WhatsApp (com ou sem mídia)
2. Arraste o arquivo para a área de upload ou clique para selecionar
3. Visualize as mensagens organizadas
4. Use o menu lateral para filtrar e exportar
